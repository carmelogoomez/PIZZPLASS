# Municipios

municipalities.json agrupa los municipios de las 47 provincias de la España peninsular.
Se excluyen Baleares, Canarias, Ceuta y Melilla por el ámbito de este formulario.
Fuente: https://github.com/codeforspain/ds-organizacion-administrativa (data/provincias.json y data/municipios.json).
Fuente original INE: https://www.ine.es/daco/daco42/codmun/26codmun.xlsx
Edición declarada: 1 de enero de 2026. Descarga: 29 de septiembre de 2026.
Licencia del dataset: Open Data Commons PDDL https://opendatacommons.org/licenses/pddl/
Transformación: agrupación por provincia_id, inversión para mostrar primero los artículos
pospuestos (por ejemplo «Puebla del Río, La» → «La Puebla del Río»), corrección del
nombre de A Coruña en el fichero de provincias y ordenación alfabética.
Los datos se incluyen en la web: no se consulta un servicio externo durante el formulario.
